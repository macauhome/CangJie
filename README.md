# CangJie practice game
# 倉頡練習
Introduction
The Cangjie Practice application is a gamified learning tool designed to help users master the Cangjie input method—a popular Chinese character input system based on character decomposition into radicals. The application provides an interactive, progressive learning experience through five difficulty levels, supporting dual input modes (English letters and Chinese radicals), streak-based scoring, and persistent progress tracking via cookies. It is built as a single-file HTML application with embedded JavaScript and CSS, using vanilla JS without external dependencies.

The target audience includes learners of Chinese typing, input method enthusiasts, educators, and developers interested in language technology. The app emphasizes usability, immediate feedback, and motivation through visual rewards and incremental challenges. Key features include level unlocking based on score and completion thresholds, real-time statistics, a built-in Cangjie keyboard, and a developer test mode for debugging.

This document provides a comprehensive analysis of the application’s structure, functionality, and educational design, with detailed code-level insights and architectural diagrams.
